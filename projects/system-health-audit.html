Overview

A PowerShell script that checks a machine's health and basic security posture — the kind of checks an IT support technician runs when diagnosing "why is this computer slow" or "is this machine configured securely." It generates a clean, colour-coded HTML report so results are easy to read at a glance.

Built to run on both macOS and Windows using PowerShell 7, detecting the operating system at runtime and adapting each check accordingly.

What it checks

  • Disk space (flags anything under 15% free)
  • Memory usage
  • Admin/root-level account membership (security check)
  • Firewall status
  • Last OS update history
  • Battery health — cycle count and condition (macOS laptops)

Tech used

PowerShell 7 (cross-platform), native OS command-line tools (vm_stat, dscl, system_profiler, Get-CimInstance), HTML/CSS for the generated report.

How it works

The script uses PowerShell 7's built-in $IsMacOS / $IsWindows variables to branch each check by operating system, since Windows and macOS expose system information completely differently. For example, memory usage on Windows comes from Get-CimInstance Win32_OperatingSystem, while on macOS it's parsed from the vm_stat command's page-based output.

Each check result is stored as a structured object (category, detail, status), then looped over at the end to build a single colour-coded HTML report — green for OK, yellow for warning, red for fail.

Challenges & what I learned

  • Hit a real install error part-way through — Homebrew recently migrated PowerShell from a "cask" to a "formula," so brew install --cask powershell failed with "No Cask with this name exists." Fixed by switching to brew install --formula powershell. A small but real example of the kind of troubleshooting that comes up constantly in IT support work — tools and package names change, and knowing how to search the error and adapt is the actual skill.
  • Learned that Windows and macOS expose almost every piece of system information differently (disk, memory, admin groups, firewall), which meant writing OS-aware logic rather than one-size-fits-all commands.
  • Extended the script myself to add a battery health check (cycle count + condition), since that's a genuinely useful diagnostic for laptop hardware that isn't covered by the original checks.

Development note

This script was built with AI-assisted development (Claude), then run, debugged, and adapted for cross-platform compatibility by me. I extended it with an additional battery health check as part of learning the underlying PowerShell concepts.
